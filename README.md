## Rules:
1. If developing separately for __mobile__ in a diffrent env, push to `mobile` branch.
2. If developing separately for __desktop__ in a diffrent env, push to `desktop` branch.
3. If developing for both __desktop__ and __mobile__ in an integrated code base and env, push to `dev` branch.
4. For code base to be test, push to `test` branch. Consider this as pre-final code.
5. You would need 2 approvals to push to `main` branch, so I will be one of the gate keepers.
